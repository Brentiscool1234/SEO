# Icons

Place your icon files here:
- `icon.ico`  — Windows (256x256 recommended, multi-size ICO)
- `icon.icns` — macOS
- `icon.png`  — Linux (512x512)

You can generate all three from a single PNG using:
- https://icoconvert.com (ICO)
- https://cloudconvert.com/png-to-icns (ICNS)

Also copy `icon.ico` to `electron/icon.ico` (used for the tray and NSIS installer).
